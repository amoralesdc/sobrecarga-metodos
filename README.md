# Sobrecarga de métodos

Clase `Calculadora` con tres versiones del método `sumar()`: una para dos enteros, una para tres enteros y una para dos decimales.

## Compilar y ejecutar

```bash
g++ calculadora.cpp -o calculadora
./calculadora
```

## Salida

```
Dos enteros: 5 + 3 = 8
Tres enteros: 5 + 3 + 2 = 10
Dos decimales: 2.5 + 3.7 = 6.2
```
